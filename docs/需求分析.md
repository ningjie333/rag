# 需求分析

> 项目：学科知识整合智能体（AI + 兽医知识）
> 版本：v1.0 | 更新：2026-05-10

---

## 一、项目目标

本项目旨在构建一个基于 AI 的学科知识整合系统，面向兽医教育领域，实现从多本教材 PDF 到结构化知识图谱、再到跨教材知识去重整合与 RAG 智能问答的完整链路。

**核心目标：**

| 目标 | 说明 |
|------|------|
| 多教材导入 | 支持 PDF/TXT 格式教材上传，自动解析为结构化文本 |
| 知识图谱构建 | 利用 LLM 从文本中提取知识点、定义、关系，形成图结构 |
| 跨教材去重 | 对多本教材中的重复概念进行语义对齐和合并，压缩比 ≤30% |
| RAG 问答 | 基于向量检索 + LLM 生成，提供带精准引用的问答服务 |
| 整合报告 | 自动生成多教材知识整合的可读报告，支持预览和下载 |

## 二、问题分解

### 问题 1：如何从 PDF 提取结构化知识

**挑战：** PDF 教材包含章节、段落、图表说明、脚注等混合格式，纯文本解析会丢失结构信息。

**方案：**
- 使用 PyMuPDF 进行 PDF 解析，保留页码和文本顺序
- 采用滑动窗口分块策略（chunk_size=500, overlap=50），确保语义完整性
- 分块结果存入 ChromaDB，附带 book_title、page、chunk_index 等元数据

### 问题 2：如何构建知识图谱

**挑战：** 知识点之间的关系（前置、包含、关联）隐含在文本中，需要语义理解能力。

**方案：**
- 调用 LLM 对每个 chunk 提取知识点（concept/fact/definition）
- 多信号融合推理关系：语义相似度（50%）、SimHash（30%）、共现分析（20%）
- DFS 去环确保图谱为有向无环图（DAG）
- 同名概念合并，保留来源信息

### 问题 3：如何跨教材去重合并

**挑战：** 不同教材对同一概念可能有不同表述（如"细胞呼吸"vs"呼吸作用"），需要语义对齐。

**方案：**
- 基于 embedding 余弦相似度检测跨教材相似概念
- LLM 辅助判断是否为同一概念（处理同义词、别名）
- 合并后保留所有来源引用，标记同义词关系
- **量化指标：** 压缩比 = 整合后节点数 / 原始节点总数 ≤ 30%

### 问题 4：如何实现带引用的 RAG 问答

**挑战：** 用户需要知道答案来自哪本教材的哪一页，不能只有 AI 生成的内容。

**方案：**
- 用户问题 → ChromaDB 向量检索 Top-K chunks → 构建上下文 prompt
- LLM 基于上下文生成回答，附带 citations 数组
- 每个 citation 包含：chunk_id、原文截取、来源书名、页码、相似度分数

### 问题 5：如何生成可读的整合报告

**挑战：** 整合结果需要以人类可读的方式呈现，包含统计数据和具体示例。

**方案：**
- 后端自动生成 Markdown 格式报告，包含概览统计、去重示例、跨教材关联
- 前端使用 marked 库渲染 Markdown，支持在线预览和下载

## 三、用户场景

### 场景 1：学生备考

> 兽医专业小王正在准备期末考试，他有 3 本教材的 PDF。上传后系统自动提取知识点、构建图谱，他可以通过问答快速查找"心肌炎的诊断方法"，并看到来自不同教材的引用来源。

**使用流程：** 上传教材 → 等待图谱构建 → 提问 → 查看带引用的回答 → 导出复习报告

### 场景 2：教师备课

> 李教授需要为"兽医病理学"课程准备教案，希望了解不同教材对同一知识点的讲解差异。上传多份教材后，通过知识图谱查看概念间的关联，利用整合报告发现跨教材的补充内容。

**使用流程：** 上传教材 → 查看知识图谱 → 浏览跨教材关联 → 导出整合报告用于备课

### 场景 3：自学

> 自学者小张从网上收集了多份兽医学习资料（TXT/PDF），希望系统帮他去除重复内容、梳理知识体系。上传后系统自动去重合并，生成精简的知识图谱和整合报告。

**使用流程：** 上传多份资料 → 触发跨教材整合 → 查看去重后的图谱 → 浏览整合报告

## 四、功能列表

### 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 教材上传 | 支持 PDF/TXT 格式，拖拽上传，显示解析进度 | P0 |
| 知识图谱展示 | 可视化节点和边，支持缩放、拖拽、点击查看详情 | P0 |
| RAG 问答 | 输入问题，返回 AI 回答 + 引用来源列表 | P0 |
| 多轮对话 | 支持追问，保留对话上下文 | P1 |
| 跨教材整合 | 多教材去重合并，压缩比 ≤30% | P1 |
| 整合报告 | 在线预览 + 下载 Markdown 报告 | P1 |

### 辅助功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 教材管理 | 查看已上传教材列表、分块数量 | P0 |
| 节点详情 | 点击节点查看名称、描述、来源教材 | P0 |
| 颜色映射 | 不同教材节点分色，节点大小映射频次 | P1 |
| 健康检查 | API 健康状态监控 | P2 |

## 五、非功能性需求

| 需求 | 指标 |
|------|------|
| 压缩比 | 跨教材整合后 ≤ 30% |
| 响应时间 | RAG 问答 ≤ 10 秒（含 LLM 调用） |
| 并发 | 支持单用户操作（黑客松阶段） |
| 浏览器 | Chrome / Edge 最新版 |
| 分辨率 | 1920×1080 |
